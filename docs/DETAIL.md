# 本地账本（dsh-ledger）

## 它是什么

`dsh-ledger` 是 DSH 的账本面板：Agent 读账单、生成待确认记录，你批准或驳回，到期核对余额。账本是本地纯文本 Beancount，可读、可备份、可带走。

交易写 `trans/collect.bean`，对账写 `trans/reconciliation.bean`，`main.bean` / `account/*.bean` 是账户与结构配置。没有服务、数据库或账号。

## 开始使用

首次打开时点「安装 / 修复账本引擎」，然后创建账本（填名称、选空目录），或直接打开已有 `main.bean` 的目录。

## 三个入口

### 审核

- **待对账**：按账户设置的对账周期列出到期、逾期或未对账的资产/负债账户；
- **待审核**：Agent 或补记产生的草稿，只读，只能批准或驳回；
- **补记**：次级入口，用于现金、转账、收入等没有来源的条目；保存后仍进草稿队列。支出/收入可以选择父账户或子账户，资产/负债只能选最末级账户。

### 对账

- 打开表单先显示预期余额、上次对账，以及本次是新建还是更新；
- 你只填**实际余额**；差额非 0 时才出现「差额分配」，没分完的默认记入权益调整；
- 提交时会确认预览之后账本没有被改动；校验通过才写入，失败不会改动账本；
- 同一个对账日期再次提交会更新最近一次记录，旧记录标记为已替换；更早期间不可改；
- 对账后仍可补记该日期之前的草稿，差额会自动平账。

### 账户

- 五类树：Assets / Liabilities / Equity / Income / Expenses；
- 能否记账取决于账户是否已开立：资产/负债的分组节点只是分类，只有最末级账户可编辑、可记账、可对账；支出/收入的分组本身也可以记账；
- 资产/负债的最末级账户显示当前余额（只读）；余额为 0、有成本或持仓、支出/收入/权益不显示金额；
- 别名就地编辑；资产/负债的最末级账户可改周期或在详情内对账，有子账户时不能改周期；
- 新增账户走弹窗（路径 + 别名），默认使用账本币种，开立日默认为当天。

## 为什么可信

- Core 是唯一写者：Agent 只能提交草稿，不能直接改账本；
- 你批准后，整本账先校验，通过才写入；
- 校验失败时账本保持原样，不会写一半；插件不改写、不重试、不兜底。

## 数据与备份

```text
ledger/
├── main.bean
├── account/*.bean
├── trans/collect.bean
├── trans/reconciliation.bean
└── .ledger/              # 草稿、锁、审计、对账历史
```

账本真相只在 `.bean`；`.ledger/` 可删，但会丢草稿与审计。Git 忽略 `.ledger/`、`.venv/`，交易与对账文件必须跟踪；Core 不自动提交。

## 边界与限制

- Core 是唯一写者；插件不含账本规则，不直接写文件。
- Agent 只能提交草稿/结构提案，批准由人触发；同 OS 用户 + 全 shell 下仍可绕过 `AGENTS.md` 改文件。
- 默认单币种；多币种账户不对账。
